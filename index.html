I'm Duck, a Minecraft developer specialising in custom private plugins for servers and full server setups. I don't do public releases — every plugin I write is purpose-built for the server that commissioned it, meaning cleaner code, tighter integration, and no bloat from trying to please everyone.

With 5+ years across Spigot, Paper, and Fabric, I've built everything from lightweight utility plugins to full custom game modes. If you can imagine it in Minecraft, I can build it.
